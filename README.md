Welcome to Forklift-Warriors
Created by Hank Davidson, Steven Drain, Kenzie Burt, Jerry Denning, Jaden Rogers

Description:
Our forklift simulation is a fun and engaging way to make learning forklifts easy and accessible with the help of VR. With accessibility features in mind, our experience allows first time forklift users an interactive environment to play around with the basics of forklift navigation. With the combined talent of programmers, 3D Artists, Sound Design and Level Design, our team had a wonderful time working with one another to create this experience. 
The Main goal of our experience is to grab marked pallets/boxes and place them in their designated drop off zones. This is done by using your “forks” on your forklift to pick up the pallets and using the forklift to navigate the warehouse to the designated zones in the rafters or in the back of trucks. We wanted this to be a very simple step before getting into an actual forklift, because of this some of the actual movement and tutorial has been simplified a lot.
How to Play:
Analog Sticks
Left Moves forklift forward and backward
Right Moves it left to right
Triggers
Grab items
Clipboard
Rotate left wrist to make the clipboard appear this has all the accessibility functionality on it
The clipboard has
Start Menu
High Contrast UI
Distance Interactors
Worker Toggle
Waypoints
Subtitles and Audio Dropdown
Objective:
Move boxes into the green box, get all the boxes placed where they need to go in order to pass the training!
